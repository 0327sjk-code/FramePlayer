# PlayerUI UX 验收草案

## 空状态与加载

- 首次启动显示“拖入 PNG 序列文件夹或视频文件”，并提示使用下方“打开文件夹／打开当前序列”；画布中央不放置按钮。
- 用户取消系统文件夹选择器后不显示错误，也不改变当前状态。
- 首帧尚未提交时显示静态加载文字和骨架，不显示旋转动画。
- 新文件夹或重扫失败时保留旧画面、旧时间轴和旧序列名；错误只出现在底部状态行。

## 顶部来源栏与底部控制区

- 顶部只显示来源路径和总帧数；所有按钮、输入框、解码、遮罩和导出操作必须位于底部。
- 底部始终显示“打开文件夹”“打开当前序列”“重扫”“对比画面”和“重置画面”；进入双画面后“对比画面”切换为“退出对比”。尚未成功拖入 PNG 序列时禁用“打开当前序列”，视频模式禁用“重扫”。
- “打开当前序列”只读取最近一次成功拖入的 PNG 序列目录；选择器、重扫和视频拖入不得覆盖该记录。
- 序列名过长时不挤压内存和解码控件，悬停可以查看完整文本。
- 内存输入严格限制在 `4–48 GB`；输入 `3` 提交后显示 `4`，输入 `64` 提交后显示 `48`。
- 解码比例只允许 `25% / 50% / 75% / 100%`；低于 `100%` 的选项和画布角标同时显示“缩放预览”。
- 切换解码比例后，旧代次解码结果不得上传；对比模式只显示最后一次左右完整提交的比例，失败回滚期间不得短暂显示单侧新比例。新帧到达时复用同一 D3D11 动态纹理并覆盖内容，不销毁渲染设备。

## 画布

- PNG 或视频画面始终完整按比例适配可用画布，不裁切、不拉伸。
- 鼠标左键按下但移动不足 `2 px` 时不跳帧。
- 横向累计移动 `+2 px / -2 px` 时分别移动 `+1 / -1` 帧，持续移动按 `0.5 frame/px` 计算。
- 开始擦帧时立即暂停；松开后保持在目标帧，不恢复播放。
- 擦帧请求只提交最新目标帧；目标严格限制在 `[0, 总帧数 - 1]`。
- 缓冲状态同时显示中文“缓冲中”和前方已就绪秒数，不能只用颜色表达。
- 滚轮以鼠标位置为中心执行 `25%–1600%` 缩放；右上角显示非 100% 视图比例。
- 中键拖动画面时不暂停、不 Seek；“重置画面”恢复当前选中画布的适应窗口并居中。

## 双画面对比

- 点击“对比画面”后，原画布拆为左右两侧；右侧为空时显示拖入视频或 PNG 序列的引导。主要交互覆盖视频↔视频和序列↔视频，底层兼容其他左右来源组合。
- 拖放落点位于右侧画布时，只把该来源加载到右侧；不得替换左侧主来源。右侧成功提交后左右统一跳到第 1 帧。
- 共享总帧数取 `max(左总帧数, 右总帧数)`。短侧越界后必须是纯黑，不停留末帧；时间轴拖回有效帧时恢复该侧画面。
- 左右使用唯一共享播放时钟和共享帧号。有效目标帧必须成对原子提交；一侧尚未就绪时不得让另一侧先显示新帧。越界纯黑作为已就绪结果参与提交。
- 播放、暂停、逐帧、画布擦帧、时间轴、播放范围、FPS、循环、解码比例、遮罩和总内存均同步作用于左右两侧。
- 点击、滚轮或中键操作会选中对应画布；左右分别保存缩放、中心和中键平移状态。“重置画面”只复位选中侧，另一侧不得变化。
- 对比模式下左右来源先居中放入固定 `1920×1920` 虚拟画布，遮罩只裁切画布开口。匹配开口尺寸的已裁视频必须完整显示，不得再次裁切；小来源的空余区域保持纯黑。所有遮罩与无遮罩都使用相同的完整方画布缩放，opening 只能成为同比例子矩形，不能单独放大到 Pane；左右最终可见素材的内侧边缘统一贴中线，越界虚拟画布由各自 Pane 裁掉。
- 默认 25 GB 仍是进程总内存目标；对比模式左右缓存各使用可用预算的 50%，底部缓存数字显示两侧合计值。
- 点击“退出对比”后只释放右侧来源、纹理、缓存和视图；左侧来源、当前帧、缓存及缩放状态继续保留。再次进入时右侧为空。
- 导出始终只使用左侧主来源；右侧素材、纯黑越界帧和左右布局不进入 MP4。

## 时间轴与播放

- 时间轴滑块、当前帧数字、当前秒数和实际显示画面始终使用 `currentFrame`，缓冲期间不提前跳到 `requestedFrame`；第一帧为 `0.00 秒`。
- 时间轴不绘制白色播放进度线；当前帧只由薄荷绿外圈与淡薄荷白中心的圆形游标表达。4 px 明亮薄荷绿表示当前前方连续就绪的即时缓存，8 px 森林绿表示后台缓存总量；MP4 导出进度继续独占高饱和亮绿色。
- 悬停时间轴必须显示“播放位置／即时缓存／后台缓存”三行同色说明；非循环即时缓存不得越过自定义末帧，循环跨末帧时拆成首尾两段。
- 对比模式的时间轴、范围手柄和总帧标签使用左右较长来源的总帧数；循环和非循环边界同样以共享最长范围为准。
- 按下时间轴立即暂停，拖动位置映射到 `[0, 总帧数 - 1]`，最左和最右可精确到首尾帧。
- `Left`、`Right` 每次严格移动一帧；按住 `Shift` 不改变步长。
- `Space` 播放／暂停，`Home` 当前范围起始帧，`End` 当前范围结束帧，`L` 切换循环。
- 播放范围起始/结束支持 1-based 数字输入；Enter 或失焦提交后更新范围并跳到对应端点。
- FPS 控件限制为 `1–120`，默认显示 `60 FPS`。

## 缓存、状态与错误

- 底部持续显示：已缓存帧数／总帧数、前方就绪秒数、缓存内存／上限、目标 FPS、实际 FPS、掉帧数；对比模式的缓存内存为左右合计值，但上限仍是同一个进程总目标。
- 缓存完成同时显示“缓存完成”文本和绿色状态；缓冲时显示黄色“缓冲中”文本。
- D3D11 纹理上传失败、文件夹加载失败、重扫失败均为非模态内联错误。
- “查看详情”展开完整错误；“清除”仅隐藏当前错误，不修改素材、不弹窗、不清空当前序列。

## DPI 与窗口尺寸

- 在 Windows `100% / 125% / 150% / 200%` DPI 下检查文字无裁切、按钮仍可点击。
- 在 `800×560`、`1339×760`、`1340×760`、`1440×900` 和超宽窗口检查顶部来源完整、底部控件不重叠、播放组严格居中。
- 窗口缩放期间重新计算画布适配矩形并保留归一化视图中心，不改变当前帧或播放状态。
- 对比模式在上述尺寸和 DPI 下必须保持左右画布、分隔线和选中边界可辨；所有预设均以最终可见素材内侧边缘贴近中线，不能相互覆盖或被底部控制区裁切。独立缩放或平移后点击“重置画面”必须恢复完整方画布的统一缩放和对应基础对齐。
