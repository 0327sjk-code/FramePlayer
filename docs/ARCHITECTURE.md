# 序列播放器架构

## 项目结构

```text
src/App        应用生命周期与模块编排
src/Core       序列索引、单来源引擎、双画面对比协调器、共享播放时钟和任务调度
src/Imaging    WIC PNG 解码；Media Foundation 视频探测、硬件解码与百分比缩放
src/Cache      按字节预算管理的纯 RAM 帧缓存
src/Export     不可变导出快照、ffconcat、NVENC 进程、码率策略与事务提交
src/Render     D3D11 设备、纹理复用和画面呈现
src/UI         Codex 式 ImGui 中文界面、时间轴、双手柄播放范围与擦帧交互
src/Platform   Win32 窗口、文件夹选择、拖放与极小注册表设置
tests          无窗口单元测试与集成测试
```

## 模块边界

- `SequenceSession` 持有不可变文件清单和递增的会话代次。
- `DecodeScheduler` 只决定任务优先级，不直接管理 UI 或 GPU。
- `WicImageDecoder` 接收路径与解码比例，返回不可变 BGRA 帧。
- `MemoryFrameCache` 只按真实字节数计费，缓存预算与淘汰独立于解码器。
- `FrameTexture` 每个画布复用一张独立 D3D11 动态纹理；上传去重键包含单画面／成对画面域、Generation、FrameIndex 与 Revision，模式切换时不会因修订号碰撞复用旧帧。
- `PlayerEngine` 管理单一 PNG 序列或视频来源；`ComparisonPlayer` 持有主引擎与可选右侧引擎，对外提供统一播放、范围、FPS、解码和内存命令。
- `ComparisonPlayer` 的共享时间轴使用左右总帧数的最大值。目标帧超出某一来源时，该侧以“无帧可用”参与提交，UI 清空对应纹理并显示纯黑。
- `ComparisonPlayer` 是唯一的对比播放时钟；左右有效目标帧只有在同一共享帧号下全部就绪后才更新成对修订号，避免单侧先显示新帧。
- `PlayerUI` 只通过 `ComparisonPlayer` 公开命令发起加载、播放和定位，不直接操作线程或缓存容器；Win32 拖放落点与 ImGui 画布矩形统一使用客户区坐标，命中右画布后路由到 `LoadSecondarySource`。
- `PlayerEnginePolicy` 集中管理缓存容量、后台回压和预读窗口等无状态策略，便于独立测试。
- `PlaybackRange` 使用 0-based、首尾包含的索引；UI 只负责转换为 1-based 标签，播放、预读和就绪秒数共用同一范围边界算法。
- `SequenceExportSnapshot` 在引擎锁内固定会话、范围和 FPS，锁外复制有序文件列表；不包含预览解码比例或 RAM 缓存。
- `Image2SequenceInput` 只检查所选范围；同目录、固定数字宽度且严格连续时生成 image2 pattern，否则回退 ffconcat。
- `FfmpegExportController` 在独立 `jthread` 中生成短暂文本清单、隐藏启动 NVENC、解析真实帧进度，并在成功后才原子提交最终 MP4。

## 数据流

```text
文件夹选择 / 拖放
        ↓
PNG 扫描 + 自然数字排序
        ↓
新 SequenceSession（尚未提交）
        ↓
首帧按当前百分比解码成功
        ↓
原子替换当前会话 + 递增代次
        ↓
播放时钟产生目标帧
        ↓
自定义播放范围约束连续播放目标
        ↓
P0 当前帧 → P1 前向预读 → P2 邻域 → P3 后台全序列
        ↓
WIC PNG 解码 + Fant 高质量缩放 + 32bpp BGRA

视频文件 → Media Foundation SourceReader → 单工作线程顺序解码/随机 Seek → 32bpp BGRA
        ↓
按 25 GB 默认内存目标计算 RAM LRU 预算
        ↓
D3D11 动态纹理上传
        ↓
ImGui 画布呈现

“对比画面”
        ↓
创建右侧 PlayerEngine + 左右启用外部时钟
        ↓
按拖放落点把来源提交到右侧
        ↓
右侧首帧成功后共享帧重置为 0
        ↓
共享总帧 = max(左总帧, 右总帧)
        ↓
共享播放 / 逐帧 / 擦帧 / 范围 / FPS / 循环
        ↓
有效帧等待解码；越界侧标记为纯黑就绪
        ↓
左右结果成对原子提交到独立 D3D11 纹理
        ↓
1920×1920 虚拟画布合成与统一 Fit → 开口/内容映射 → 可见内容内缘对齐 → Pane 裁剪

导出按钮
        ↓
仅主来源的不可变 SequenceExportSnapshot + 当前归一化遮罩
        ↓
连续编号 image2 高速输入 / 非连续 ffconcat 回退
        ↓
居中裁切 + 显式 RGB full→BT.709 limited + NV12 + HEVC Main p5 NVENC
        ↓
90 MB 复核 / 必要时降码率重试
        ↓
.part 原子改名为“导出目录名[序号].mp4”
```

## 缓存与取消

- 不存在硬盘图片缓存层。
- 用户设置进程内存目标；运行时默认预留 512 MiB 给解码与上传，剩余作为图片 LRU 预算。
- 内存目标是整个进程的全局预算。单画面由主引擎使用全部可用 LRU 容量；对比模式将同一可用容量按左右 50/50 分配，两个引擎的缓存之和不得超过全局容量。
- 实时采样进程私有内存；达到目标约 98% 时停止新增后台任务，P0/P1/P2 交互解码仍可继续。
- 解码比例按宽、高同时缩放；帧内存近似按比例平方变化。
- 每个任务携带会话代次与解码比例代次。代次不匹配的结果立即释放。
- 同一帧同一代次最多存在一个正在执行的任务。
- 内存降低时优先淘汰距离播放头最远、最近最少使用且未固定的帧。
- 暂停或刚加载时，后台完整缓存最多使用 4 路解码；开始播放后自动限制为 1 路。
- P0/P1/P2 始终高于后台任务，后台并发变化不会改变当前帧的优先级。
- 自定义范围只约束连续播放的热窗口；后台任务仍扫描完整序列，最终可以缓存范围外图片。
- MP4 不读取预览缓存；目标目录中的 `.ffconcat` 与 `.part.mp4` 只在任务运行时存在，完成、失败、取消及退出都会清理。
- 退出对比时先停止并销毁右侧引擎、纹理、缓存和视图状态，再把完整缓存预算归还主引擎；主来源的会话代次和缓存不重建。

## 第一版验收边界

- 加载并显示 `F:\Render\众人兜鱼` 当前扫描到的 PNG；目录可在渲染过程中继续增长，不硬编码帧数。
- 默认 60 FPS、25 GB、100% 解码。
- 方向键一次严格移动一帧。
- 时间轴和画布左键拖动均能定位，画布灵敏度为 0.5 frame/px；滚轮缩放和中键平移只改变 D3D11 绘制矩形，不触发解码、缓存或 Seek。
- 双手柄播放范围支持完整范围、自定义范围、单帧范围、循环回绕与非循环停止。
- “对比画面／退出对比”可在单画面和左右画布之间切换；右侧支持视频与 PNG 序列，主要验收视频↔视频和序列↔视频，底层兼容其他组合。
- 右侧来源成功后左右从第 1 帧开始；共享总帧取最大值，短侧越界纯黑并在回到有效帧后恢复，循环以最长素材末帧为边界。
- 对比模式的播放、逐帧、擦帧、范围、FPS、循环、解码比例、遮罩和总内存设置同步；缩放、中键平移和重置按当前选中画布独立。解码比例使用双路 Apply／Rollback 事务，双方成功后才更新共享值，任一失败则恢复旧比例且不提交混合代次画面。
- 对比遮罩不直接把归一化开口套到来源纹理：每侧先按原始来源尺寸居中映射到固定 `1920×1920` 虚拟画布，超大来源等比缩小，小来源保留黑边；来源与开口求交后计算 `sourceUv` 和相对完整方画布的 `targetInCanvas`。UI 始终 Fit 和导航完整方画布，再把 opening 与 target 映射到变换后的 canvas；opening 只负责 Clip，绝不单独 Fit。匹配尺寸的已裁视频使用完整 UV。所有遮罩及无遮罩都平移完整画布，使最终可见素材内侧边缘贴中线，再由 Pane Clip 裁掉越界区域。该基础对齐先于左右独立 Zoom/Pan，左右有效帧仍使用同一共享帧号成对提交。
- 解码比例和内存目标可在运行时修改。
- 退出后没有新增图片缓存文件。
- Windows 可能按系统策略分页；应用本身不创建图片缓存文件。
- 快速切换比例或文件夹时不显示旧会话帧。
- 首帧/末帧按钮跳到自定义边界；MP4 继承遮罩、FPS 和 inclusive 范围。
- 对比模式不改变导出来源：MP4 始终只读取左侧主来源，右侧对比素材及纯黑越界段不进入导出。
- 60 秒、60 FPS、1920×1920 的 HEVC MP4 小于 90,000,000 字节，并在本机 NVENC 上小于 60 秒完成。
- 当前真实 2493 帧、41.55 秒、1920×1920 序列通过 image2 + HEVC Main p5 在 9.846 秒完成，输出 87,334,905 字节；旧 ffconcat 链路同量级约 118 秒。
