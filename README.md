# 序列播放器

面向 Windows 11 的原生 PNG 序列与视频播放器。核心目标是在 NVMe/SSD 上直接观看数千张 PNG 或常用视频文件，并在播放期间按照用户指定的内存目标渐进缓存。

## 第一版功能

- 原生 `C++20 + Win32 + Direct3D 11 + WIC + Dear ImGui`。
- 中文 Codex 式深色界面，不使用网页、Electron 或本地 HTTP 服务。
- 默认 `60 FPS`、`25 GB` 内存目标、`100%` 原始像素解码。
- 支持 `25% / 50% / 75% / 100%` 解码比例。
- 图片缓存只存在于 RAM，退出后由系统自动释放。
- 应用不创建图片缓存文件或缓存目录，不修改源 PNG；Windows 仍可能按系统策略将进程内存分页到磁盘。
- 可直接拖入 PNG 序列文件夹、单张 PNG（自动使用所在目录）或 MP4/MOV/M4V/WMV/AVI/MKV/WebM；视频由 Windows Media Foundation 硬件解码，缓存仍只保存在 RAM。
- 底部“对比画面”可开启左右双画布；把来源拖到右侧即可加载对比素材，按钮随后显示“退出对比”。主要支持视频↔视频和序列↔视频，底层仍兼容其他左右来源组合。
- 右侧来源成功后两侧统一从第 1 帧开始。共享时间轴取左右总帧数的最大值；短素材越界后该侧显示纯黑，拖回有效帧后恢复，循环以最长素材末帧为边界。
- 对比播放使用唯一共享时钟，左右有效帧成对原子提交；播放、逐帧、擦帧、范围、FPS、循环、解码比例、遮罩和总内存设置均同步作用于两侧。
- 最近一次成功拖入的 PNG 序列目录会保存为轻量路径设置；“打开当前序列”可在重启后重新打开。文件夹选择器、重扫和视频拖入不会覆盖该记录。
- 方向键每次只移动一帧。
- 时间轴拖动与画布左键横向擦帧；画布灵敏度为 `0.5 frame/px`。
- 鼠标滚轮以光标位置为锚点执行 `25%–1600%` 视图缩放；按住鼠标中键拖动画面，“重置画面”恢复适应窗口并居中。缩放和平移只改变预览绘制，不增加解码或缓存。
- 对比模式下左右缩放和平移状态独立；点击画布后，“重置画面”只复位当前选中的一侧。
- 当前帧区域同步显示基于目标 FPS 的秒数；所有按钮、内存、解码、遮罩和导出操作集中在底部，播放控制固定居中。
- 独立双手柄滑块与 1-based 数字输入可设置包含首尾的播放起始帧与结束帧；输入提交后立即跳到对应端点。连续播放只在所选范围内循环或停止，手动逐帧与擦帧仍可查看完整来源。
- 居中遮罩支持“无遮罩”、`1080×1080`、`1920×1080`、`1080×1920`、`864×1080`；预览显示遮罩，MP4 导出按同一开口居中裁切。
- 对比模式的左右来源先居中放入各自固定 `1920×1920` 虚拟画布，再由遮罩裁切画布开口；已裁成 `1080×1920 / 1920×1080 / 1080×1080 / 864×1080` 的匹配视频不会被重复裁切。所有预设始终按完整方画布适应窗口，遮罩只缩小可见子矩形而不放大画面；左右最终可见素材的内侧边缘统一贴近中线，越出 Pane 的虚拟黑边由裁剪区域隐藏。
- 后台导出 H.265/HEVC MP4，固定读取 100% 原始 PNG，并锁定开始时的遮罩、FPS 与包含首尾的播放范围。
- 连续编号 PNG 自动使用 FFmpeg `image2` 高速输入；缺帧、混合命名或非连续序列自动回退兼容的 ffconcat 输入。
- 导出使用 NVIDIA NVENC、HEVC Main `p5`、`hvc1`、BT.709 与无音频 CBR；按时长动态使用 90,000,000 字节预算内的最高目标码率，超限自动降码率重试。
- RGB 像素先显式执行 full-range RGB → limited-range BT.709 矩阵转换，再写入一致的 BT.709 标签，避免默认矩阵导致饱和度偏高。
- 导出位置保存在 `HKCU\Software\ZTSequencePlayer`；文件名使用导出目录名，重名自动按 `名称01.mp4`、`名称02.mp4` 顺延。
- 导出只在目标目录短暂创建文本清单和 `.part` 视频，成功、失败、取消及正常退出都会清理；不创建图片缓存目录。
- 按钮、循环开关、时间轴和画布擦帧具备 140–180 ms 状态动画，并遵循 Windows 动画偏好。
- 多线程 WIC 解码、按字节预算的 LRU、播放优先任务调度和会话代次隔离。
- 暂停时最多使用 4 路后台解码加快填充；播放时自动收回为 1 路后台解码。
- 实时统计进程私有内存；接近内存目标约 `98%` 时暂停新增后台缓存，当前帧和交互解码仍保持可用。
- `25 GB` 始终是整个进程的总内存目标；开启对比后左右缓存各使用可用预算的 50%，不会扩张为每侧 25 GB。

## 双画面对比

1. 先按普通方式加载左侧主来源，再点击底部“对比画面”。
2. 将视频文件、PNG 文件或 PNG 序列文件夹直接拖到右侧画布；拖放落点位于右侧时只替换右侧来源。
3. 右侧成功加载后，两侧从第 1 帧同步开始。时间轴长度使用较长素材的总帧数。
4. 短素材结束后该侧显示纯黑，较长素材继续播放；把时间轴拖回短素材有效帧后，画面自动恢复。
5. Space、左右方向键、播放按钮、时间轴、画布擦帧、播放范围、FPS、循环、解码比例和遮罩均为共享操作。
6. 点击某一侧后，可单独使用滚轮缩放、中键平移和“重置画面”；另一侧视图不受影响。
7. 点击“退出对比”释放右侧解码器、纹理和缓存，左侧主来源、当前帧、缓存和视图保持可用。
8. “导出 MP4”始终只导出左侧主来源；右侧素材和双画面对比布局不会写入视频。

## 解码比例与内存

解码比例按宽和高同时缩放，因此缓存像素体积近似按比例平方变化：

| 解码比例 | 单帧像素面积 | 相同内存的理论帧数 |
|---:|---:|---:|
| 100% | 100% | 1× |
| 75% | 56.25% | 约 1.78× |
| 50% | 25% | 约 4× |
| 25% | 6.25% | 约 16× |

缓存内容始终为未经过有损压缩的 BGRA 像素。低于 100% 会降低预览分辨率，但不会修改原图。

## 使用

1. 双击 `FramePlayer.exe`，点击“打开文件夹”选择 PNG 序列，或直接拖入 PNG 序列/视频文件。
2. “打开当前序列”始终重新打开最近一次成功拖入的 PNG 序列目录；重启软件后仍然有效。
3. 左右方向键每次后退/前进 1 帧；空格键切换播放/暂停。
4. 拖动底部时间轴定位；在画面上按住鼠标左键水平拖动可擦帧，灵敏度约为 `0.5 frame/px`。
5. 鼠标滚轮以当前位置为中心缩放；按住中键拖动画面；点击底部“重置画面”恢复适应窗口并居中。
6. 底部“内存目标”可调整 RAM 预算；“解码”可选 `25% / 50% / 75% / 100%`。
7. 拖动“播放范围”左右手柄，或直接输入起始帧和结束帧；Enter/失焦提交后跳到对应端点。启用循环时结束帧回到起始帧，关闭循环时停在结束帧。
8. 底部“遮罩”默认为“无遮罩”；四个尺寸均以 `1920×1920` 画面为基准居中显示，不修改原图或缓存。
9. 点击“导出位置”可选择并持久保存目标文件夹；未配置时默认导出到当前 PNG 文件夹。点击“导出 MP4”立即开始，底部显示绿色真实帧进度。
10. MP4 使用当前遮罩、FPS 和播放范围；预览解码比例不进入导出，始终从左侧主来源的原始 PNG 读取。“首帧”和“末帧”按钮分别跳到两个范围手柄。
11. `100%`为原始像素播放；低比例为缩放预览，可用同等内存容纳更多帧。关闭程序后 RAM 图片缓存立即释放。

## MP4 运行条件

- 本机 `ffmpeg.exe` 需要位于 Windows `PATH`；程序通过隐藏子进程调用，不显示控制台窗口。
- 当前高性能路径使用 `hevc_nvenc`，需要 NVIDIA 显卡和支持 HEVC NVENC 的驱动。
- 视频预览使用 Media Foundation 与系统已安装的解码器；视频按原生 FPS 播放画面，当前版本不输出音频。
- FFmpeg 缺失、编码失败或目录不可写时仅在底部显示行内错误，不弹窗。

## 构建

环境：Visual Studio 2022 Build Tools、Windows 10/11 SDK。

```powershell
PowerShell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Configuration Release
```

构建成功后会自动运行 CTest。需要同时验证真实 PNG 的四档解码与 D3D11 上传时：

```powershell
PowerShell -ExecutionPolicy Bypass -File .\scripts\build.ps1 `
  -Clean -Configuration Release -RealPngPath "<PNG文件路径>"
```

也可以通过环境变量 `ZT_SEQUENCE_TEST_PNG` 提供路径，通用 CTest 不包含本机绝对素材路径。

构建结果默认位于：

```text
build\bin\Release\ZTSequencePlayer.exe
```

## 便携发布

```powershell
PowerShell -ExecutionPolicy Bypass -File .\scripts\package.ps1 `
  -Configuration Release -RealPngPath "<PNG文件路径>"
```

脚本会先执行干净构建和全部验证，然后在 `D:\Codex_Tool` 下建立带时间戳的独立发布目录。目录包含 EXE、第三方声明、Dear ImGui 许可证、SHA-256 清单和 ZIP。
